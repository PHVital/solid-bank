# SolidBank

A Spring Boot banking application demonstrating solid principles with a checking account management system.

## Features

- Account management (deposit, withdrawal)
- Transaction history tracking
- Exception handling
- RESTful API endpoints

## Technologies

- Java 24
- Spring Boot 3.2.4
- PostgreSQL
- JUnit 5
- Maven

## API Endpoints

- `GET /account` - Get account information
- `POST /account/deposit` - Perform a deposit
- `POST /account/withdrawal` - Perform a withdrawal
